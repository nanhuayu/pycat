# PyCat

**可编程的本地 Agent 工作台：Python SDK、原生桌面与远程项目。**

[English](README.md) · 简体中文 · [查看发布版本](https://github.com/nanhuayu/pycat/releases) · [使用指南](docs/product/user-guide_zh.md) · [开发者使用](docs/product/developers_zh.md) · [反馈问题](https://github.com/nanhuayu/pycat/issues)

![PyCat：把自己的资料和要做的事放在一起，整理成可用成果](media/pycat-hero.png)

PyCat 面向开发者、自动化实践者和需要处理真实项目的进阶用户。围绕本地或 SSH 工作区，你可以分析代码、运行命令、整理资料、处理图片，并把结果保留为可检查、可继续修改的文件。Python SDK、CLI、TUI、原生桌面、Web 工作台和消息通道共用任务执行与工具能力。

## 为什么开发者值得试一试

| 能力 | 可以用来做什么 |
| --- | --- |
| **Python SDK + 多入口** | 从脚本发起任务、消费运行事件和读取结果，再用桌面检查；基础 SDK 不需要安装 Qt。 |
| **多种模型协议** | 配置 OpenAI Chat Completions / Responses、Anthropic Messages、Ollama；图像另支持 OpenAI Images、Qwen DashScope 和 Seedream Ark。 |
| **模式与子 Agent** | 在 Chat、Agent、Plan、Review 间切换；按任务配置指令、工具类别、子 Agent 模型和上下文范围。 |
| **本地与远程项目** | 通过 SSH 操作 Windows / Linux 项目的文件和进程；也可通过独立 Web 宿主连接浏览器与终端客户端。 |
| **可扩展的工作方法** | Skills 复用方法，MCP 连接服务，能力设置选择专用模型；交互 Shell 支持继续输入与接管。 |
| **原生桌面与可观察过程** | Python + PyQt6 集成截图、剪贴板、托盘、文件预览和运行检查；桌面终端与预览无需 JS / WebEngine。 |

这些是当前的配置与集成能力，不代表所有服务、系统和任务都已达到同等兼容性。协议范围、远程条件与 SDK 示例见[开发者使用指南](docs/product/developers_zh.md)。

## 从手头的工作开始

| 你想做什么 | 可以这样告诉 PyCat |
| --- | --- |
| 分析或修改项目 | “先定位相关代码和调用关系，列出方案，再按确认的范围修改并验证。” |
| 整理一批资料 | “阅读这个文件夹里的材料，整理共同观点、差异和待确认的问题，保存成简报。” |
| 提取图片里的文字 | “识别这些截图，保留标题和段落，把不确定的地方标出来。” |
| 制作或修改配图 | “为这份介绍生成配图；保留主体，把背景改得简洁一些。” |
| 处理重复操作 | “先说明整理方案，再按日期整理文件，列出修改结果。” |

这些是任务示例。实际效果取决于模型、资料质量和已配置的工具；重要内容仍需你检查。

![三个步骤：准备资料、描述任务、检查并保留结果](media/pycat-workflow.png)

1. **准备资料**：选择项目文件夹，添加文件或截图。
2. **描述任务**：说清目标、范围和希望得到的格式。
3. **检查结果**：查看文件和执行过程，继续提出修改要求。

## 逐步扩展，按需使用

- **选择合适的模型**：连接云端模型服务或已部署的本地模型；聊天、图像生成和文字识别可分别配置。
- **复用工作方法**：在设置中管理技能，也可以按需连接外部工具。已有 Skills 和 MCP 的管理、发现与更新入口。
- **保留有用资料**：把成果整理成项目资料，管理可复用的记忆和偏好，减少反复说明。
- **处理更长的任务**：查看运行记录；需要命令行操作时，可查看 Shell、继续输入或结束进程。

## 用 Python 或终端接入

在源码根目录使用 Python 3.11+ 安装；配置好模型后即可运行：

```shell
python -m pip install .
pycat exec "分析当前项目，给出重构计划" -C . --mode plan --output-format json
pycat resume --last
```

Python 宿主可以通过 `from pycat import PyCat, RunRequest` 嵌入执行，获取流式事件、请求取消并继续已有会话。完整的模型配置、可运行示例和远程说明见[开发者使用指南](docs/product/developers_zh.md)。

Python 源码和结构化结果也适合接入外部评估程序，比较不同模型、模式或技能。**当前定位是可用于 Agent 迭代实验的基础**；自动修改自身代码、独立评估、选择和发布回滚组成的完整 RSI 闭环尚未提供。

## 开始使用

1. 打开 [Releases](https://github.com/nanhuayu/pycat/releases)，选择实际提供的版本。Windows 便携包完整解压后，在 `pycat-windows-x64` 文件夹中运行 **`pycat.exe`**。
2. 在 **设置 → 模型与服务** 配置可用的模型连接。PyCat 不附带模型额度，费用由所选服务决定。
3. 选择一个项目文件夹，先试着整理几份示例资料，再逐步增加任务范围。

首次使用可打开输入框旁的权限菜单，按需要调整为逐次确认或限制文件范围。当前桌面默认允许自动执行和访问所有本地路径。

更多操作见[使用指南](docs/product/user-guide_zh.md)。Windows 安装包与其他系统的可用版本，以发布页实际提供的文件为准。

## 使用前想了解的事

**资料只在本机处理吗？**

项目和会话保存在本地；使用云端模型、联网工具或消息平台时，相关内容会发送到所配置的服务。使用本地模型不等于所有扩展都离线。

**能直接生成图片或操作浏览器吗？**

需要分别配置支持生图的服务、浏览器或电脑操作工具。普通聊天模型并不自动具有这些能力。

**可以完全放手让它做吗？**

建议明确任务范围，并检查关键结果。模型可能理解错误；文件操作和外部工具会产生实际影响。

**遇到问题怎么办？**

在 [Issues](https://github.com/nanhuayu/pycat/issues) 中提供版本、系统和复现步骤；分享截图或日志前，请移除凭据与私人资料。
