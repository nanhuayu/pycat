# PyCat v0.1.2

> GitHub Release 发布说明

## 建议发布标题

`PyCat v0.1.2`

## 建议 Tag

`v0.1.2`

## 发布内容

PyCat v0.1.2 聚焦于让长时间运行的桌面 Agent 更可靠、更可见且更可控。
本版本将上下文、附件、会话修订、权限、模型档案和更新检查收敛为一条稳定交付线。

### 重点更新

- **上下文与工具结果管理**：大工具结果会归档，并按适当的详细级别重放。
  压缩具备明确的后台任务、结果分档和可预测重放语义，避免每次请求无限膨胀。
- **富输入与交付物**：图片、PDF、Word、Excel 和文本输入统一走会话内容流。
  新生成或修改的文件会作为交付物跟踪，可从对话中直接打开，而不再只显示原始工具文本。
- **会话修订**：支持编辑并重新发送用户消息、重新生成助手回复，以及删除不需要的对话轮次。
  修订会创建清晰的新延续，不会错误地宣称已回滚此前执行过的外部操作。
- **运行中控制**：Agent 执行时可追加引导，并能在工具轮次之间调整权限预设；
  渠道运行仍保持其更严格的能力策略。
- **模型与 Provider 档案**：常见模型默认值、能力、推理模式、上下文窗口、请求字段和
  Provider 协议行为围绕模型档案收敛。高级请求字段仍可用于 Provider 调试，
  但不引入第二套配置系统。
- **桌面交互收敛**：聊天画布、Composer 控件、运行状态、设置页面、工具调用折叠、
  Inspector 菜单和模型编辑布局进一步整理，以支持更紧凑的日常操作。
- **更新提示**：应用会在后台检查稳定的 `nanhuayu/pycat` Release 源，
  并从 About 页面和应用菜单显示结果。应用只打开 Release 页面，不尝试不安全的运行中二进制自更新。

### 兼容性与打包

- `core.version.__version__` 是唯一版本来源；CLI、GUI、wheel 和 Windows 包元数据均使用 `0.1.2`。
- 项目元数据已与仓库 `LICENSE` 对齐：PyCat 使用 **GNU Affero General Public License v3.0 only (AGPL-3.0-only)**。
- Windows 压缩包同时包含 `pycat.exe` 与 `pycat-cli.exe`。Windows 构建尚未代码签名，
  首次运行出现 SmartScreen 常规提示属于预期现象。

1. 下载并解压 `pycat-0.1.2-windows-x64.zip`。
2. 运行 `pycat.exe` 启动桌面应用。
