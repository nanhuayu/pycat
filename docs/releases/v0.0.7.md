# PyCat v0.0.7

> Release notes for GitHub Release

## Suggested release title

`PyCat v0.0.7`

## Suggested tag

`v0.0.7`

## Release body

PyCat v0.0.7 聚焦 **归档优先的工具结果处理、内容视图协议、Agent 运行时拆分、技能系统增强、UI 与样式体系整理** 五个方向。该版本延续 v0.0.6 对入口和打包边界的收敛，进一步把长内容、工具调用、子 Agent、技能加载和桌面界面反馈纳入更稳定的运行时结构。

### 本版本定位

v0.0.7 是一个偏运行时内核和交互体验的版本，重点解决 Agent 在真实长任务中暴露出的几个问题：

- 工具输出过长时，不能只依赖截断文本或一次性写入消息历史。
- 模型可见内容、用户可查看全文、后台可压缩摘要，需要有统一的视图协议。
- 子 Agent、工具循环和任务追踪需要从大型任务执行类中拆出更清晰的边界。
- 技能系统需要支持项目技能、全局技能和外部只读技能，并暴露资源读取能力。
- 桌面 UI 需要更紧凑、更一致地展示工具调用、任务状态、产物和设置页面。

## Highlights

- **归档优先的工具结果处理**：新增 `ToolCallArchiveService`，用会话归档保存重要或超长工具输出，再按策略生成模型可见视图，降低上下文膨胀和历史污染。
- **内容视图协议**：新增 `core/content/view_protocol.py`，统一 `[full]`、`[line:x-y]`、`[summary:*]` 等视图标签，并记录 exact / derived / pending 等精确度语义。
- **会话归档存储**：新增 `SessionArchiveStore` 和 `ArchiveViewService`，支持原文、摘要、主题视图、多级压缩结果和归档元数据的可恢复管理。
- **Agent 运行时拆分**：新增 `AgentRuntime`、`RuntimePolicyFactory`、`agent_loop`、`tool_loop`、`trace` 等模块，将策略构建、工具循环、子 Agent 运行和追踪事件从单一任务类中拆分出来。
- **技能系统增强**：技能加载支持外部只读技能目录，技能元数据中加入来源范围和只读标记，并提供资源列举、资源读取和执行可用性检查。
- **产物与任务 UI 优化**：统计面板新增 Artifact 列表区域，任务卡片、工具栏、输入区、侧边栏、设置页样式进一步统一。

## 从 v0.0.6 以来的主要变更

### 新增

- **内容视图协议**：新增 `ArchivePolicy`、`ToolResultViewPolicy`、`ContentViewLabel`、`ContentExactness` 等基础类型。
- **工具调用归档服务**：新增 `core/tools/tool_call_archive.py`，按工具类型决定 inline、archive、full view、line view 或 summary view。
- **归档视图服务**：新增 `core/context/archive_view_service.py`，支持按需生成摘要视图、主题视图，并回写会话消息中的归档元数据。
- **会话归档存储**：新增 `core/context/archive_store.py`，保存工具输出和长内容原文，支持 token 估算、内容摘要状态、视图写入和归档记录读取。
- **上下文维护模块**：新增 `core/context/items.py`、`core/context/maintenance.py`、`core/context/capability_compression.py`，为上下文压缩、候选记忆和归档维护提供独立模块。
- **Agent 运行时模块**：新增 `core/runtime/agent_runtime.py` 和 `core/runtime/policy_factory.py`，统一 GUI、CLI、通道和能力调用的运行策略构建。
- **任务循环拆分**：新增 `core/task/agent_loop.py`、`core/task/tool_loop.py`、`core/task/subtask.py`、`core/task/stop_policy.py`、`core/task/trace.py`、`core/task/control_messages.py`。
- **内容工具**：新增 `core/tools/system/content_tools.py`，用于列举和读取归档内容视图。
- **技能资源读取能力**：技能管理器新增资源列表、资源路径解析和分段读取接口，便于模型按需读取技能附加资料。
- **UI 工具组件**：新增 `ui/utils/theme.py`、`ui/widgets/themed_line_edit.py`，配合设置页和输入控件统一主题行为。

### 优化

- **模型可见上下文更克制**：长工具结果优先进入归档，消息中只保留精确视图、摘要视图或引用信息。
- **工具结果元数据更完整**：工具调用结果记录 view label、view kind、exactness、digest、token estimate、content id 和 archive record 等信息。
- **上下文压缩输出更结构化**：压缩结果支持 brief / detailed summary、entities、claims、memory candidates 等结构字段。
- **子 Agent 追踪更清晰**：子 Agent 运行过程可记录 prompt、thinking、完成状态、失败状态和取消状态。
- **技能目录语义更明确**：技能来源区分 project、global、external；外部技能默认为只读，避免设置页误修改。
- **搜索依赖更新**：`duckduckgo-search` 迁移为 `ddgs`，减少旧包兼容风险。
- **设置页面样式统一**：能力、渠道、模型、MCP、搜索、技能等页面使用更一致的 detail card、hover、状态色和表单控件样式。
- **聊天界面更紧凑**：输入工具栏、发送按钮、会话列表、消息卡片和工具调用卡片布局进一步收紧。
- **Artifact 展示更直接**：统计面板新增产物列表，支持从右侧面板快速打开产物文件。

### 修复

- 修复超长工具结果直接进入对话历史导致上下文膨胀的问题。
- 修复工具结果视图缺少精确度标识，模型难以区分全文、行范围、摘要和待生成视图的问题。
- 修复归档摘要状态与会话消息元数据不同步的问题。
- 修复部分任务状态、工具卡片和设置页控件在深色/浅色主题下显示不一致的问题。
- 修复 `qtawesome` 图标来源在打包环境中带来的依赖和可见性不确定性。
- 修复技能目录中外部只读技能与项目技能语义混在一起的问题。

## 架构说明

### 归档优先工具结果

```text
tool raw result
  -> ToolCallArchiveService
  -> SessionArchiveStore
  -> ToolResultViewService / ArchiveViewService
  -> assistant.tool_calls[].result + metadata
  -> model-visible exact/summary/reference view
```

本版本将工具输出的“原文保存”和“模型可见展示”拆成两个层次：

- 原文由 `SessionArchiveStore` 保存，作为可恢复事实来源。
- 视图由 `ContentViewLabel` 描述，例如全文、行范围、字符范围或摘要。
- 摘要和主题视图可以异步生成，并通过归档元数据回写到会话消息。
- 模型请求构建时根据视图策略注入更短、更稳定的上下文。

### Agent 运行时拆分

```text
RuntimePolicyFactory
  -> RunPolicy
  -> AgentRuntime / TurnEngine
  -> ToolCallCoordinator
  -> child AgentRunContext
  -> trace events
```

当前规则是：

- `RuntimePolicyFactory` 负责从 app settings、conversation settings、mode 和 skill invocation 中合成最终 `RunPolicy`。
- `ToolCallCoordinator` 负责工具循环、工具结果归档、子 Agent 调度和下一轮策略切换。
- `AgentRuntime` 为能力调用、技能调用和非 GUI 入口提供共享运行时外壳。
- `trace` 模块负责把子 Agent 运行状态附加到工具调用与 UI 事件中。

### 技能系统

技能现在可以来自：

```text
.pycat/skills/          # project skills
~/.PyCat/skills/        # global skills
external read-only dirs # user-level external skills
```

技能元数据新增 `source_scope` 和 `read_only`，并支持：

- 按技能名读取入口内容。
- 列举技能资源文件。
- 分段读取技能资源。
- 解析技能声明的执行模式、工具类别和具体工具。
- 检查当前工具暴露状态是否满足技能执行需求。

## How to use

1. 下载 `pycat-0.0.7-windows-x64.zip`。
2. 解压到本地目录。
3. 双击运行 `pycat.exe` 启动 GUI。
4. 在终端中运行 CLI：

```text
pycat-cli.exe --version
pycat-cli.exe list modes
pycat-cli.exe list providers
pycat-cli.exe list tools
pycat-cli.exe run "你好，介绍一下当前能力"
```

源码开发环境中：

```text
python main.py
python main_cli.py --version
python main_cli.py list modes
```

## Notes

- 本版本的重点是运行时与工具结果处理，不改变 v0.0.6 确立的 GUI / CLI 双入口规则。
- 工具结果可能以归档引用或摘要视图显示；需要原文时，可通过内容工具或 UI 入口读取对应归档内容。
- 摘要视图属于派生内容，发布或调试时应以归档原文作为最终事实来源。
- 外部技能目录默认按只读处理，适合引用共享技能包，但不建议由 PyCat 设置页直接修改。
- 当前 Windows 资源未进行代码签名，首次运行如出现 SmartScreen 提示属于常见现象。
