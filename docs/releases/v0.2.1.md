# PyCat v0.2.1

本次为候选构建。发行附件已重新生成；当前保留为 Release 草稿，待下述 Windows Shell 清理问题解决后再正式发布。

PyCat 是一个可编程的本地 Agent 工作台，提供 Python SDK、原生桌面、终端和远程项目入口。这个版本完善了图像、交互 Shell、技能与 MCP 管理、消息渠道，以及日常使用中的预览和运行反馈。

## 主要更新

- **账号登录与 API Key 接入**：支持 ChatGPT / Codex 和国内 WorkBuddy / CodeBuddy 浏览器授权登录，在同一工作台使用账号可用模型；也可连接 API Key 服务与本地模型。账号权限和额度由上游服务决定，登录集成属于实验性功能。
- **图像生成、编辑与识别**：支持 OpenAI Images、Qwen Image 和 Seedream 图像接口；聊天与图像服务分别配置，生成和编辑可以使用不同地址。OCR 可选择本地模型或指定视觉模型与提示词。
- **图片直接呈现在对话中**：交付图片支持 Markdown 内嵌显示，生成结果可以预览、保存并继续编辑；新增原生 SVG 预览，修复新上传或生成图片首次点击无法打开的问题。
- **可继续输入的 Shell**：在独立窗口中管理多个会话，查看输出、继续输入、发送中断和结束进程。Windows 支持 CMD、PowerShell、WSL；结束后保留已有输出供查阅。
- **统一的技能与工具管理**：Skills、MCP 集中在设置中，提供已安装与市场入口、搜索、列表详情、来源及支持的更新操作；内置 find-skills 和 skill-creator，浏览器及电脑操作后端按需配置。
- **消息渠道与附件**：新增钉钉，完善飞书等渠道的图片和文件处理。各连接支持的消息类型及平台限制有所不同，详情见用户指南。
- **更清晰的桌面体验**：默认森林绿，整理设置页布局；修复长正文的重复滚动范围，调用错误使用淡红提示；更新模型候选与推理设置，CodeBuddy 连接统一采用 CLI 标识。
- **开发者与远程使用**：Python SDK、CLI/TUI、Web 与桌面共享任务和工具服务；支持 OpenAI Chat Completions、Responses、Anthropic、Ollama 等聊天协议，以及 SSH 远程项目。
- **完整的公开使用材料**：发行包附带默认中文首页、英文 README、用户指南、开发者使用指南、PyCat 全景架构图与介绍配图，可从本地 README 打开相对链接。私有测试与详细研发文档不随包分发。

## 下载与使用

本次提供 **Windows x64 完整便携版**，包含桌面、CLI/TUI、Web、本地 OCR 和原生交互 Shell，无需另装 Python。

1. 下载并完整解压 `pycat-0.2.1-windows-x64.zip`。
2. 压缩包内的文件夹固定为 **`pycat-windows-x64`**；进入后双击 `pycat.exe`。
3. 在设置中配置模型服务，再开始对话。命令行入口为 `pycat-cli.exe`，运行 `pycat-cli.exe --version` 应显示 `PyCat 0.2.1`。
4. 需要终端或 Web 时，分别运行 `pycat-cli.exe` 或 `pycat-cli.exe serve`。

升级请解压到新目录并保留完整目录结构，应用继续使用已有的数据目录。新配置默认允许所有本地路径并自动执行；请按任务需要在权限菜单收窄，已有权限选择予以保留。运行模式和路径范围不等同于操作系统沙箱。

模型账号权限、余额和服务可用性取决于提供商；模型候选列表不代表账号一定可调用。账号登录集成属于实验功能。SSH 当前支持 Windows / Linux 远端，需 SSH 与 Python 3.11+；本次没有 Linux/macOS 二进制附件。Windows EXE 尚未代码签名。
