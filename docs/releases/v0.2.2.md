# PyCat v0.2.2

0.2.2 重点改进多会话执行、模型调用恢复、上下文压缩与长期记忆，并整理桌面交互和英文预览。

## 主要更新

- **多会话并行推进**：修复一个会话运行时，其它会话长时间只显示“正在生成”的问题；独立会话使用各自的执行状态。
- **调用恢复与上下文压缩**：改进中断流的恢复和完成状态反馈；压缩后及时更新上下文占用。模型调用失败或输出被截断时，不再把错误文本作为成功摘要。上游明确给出更小输入上限时，可在有限次数内重新分块。
- **更明确的输出预算**：区分用户设置、有效输出预算与提供商限制，减少推理耗尽输出后无最终答案时的误导提示。
- **Memory 与 Wiki**：项目记忆和用户偏好各固定为 8,000 字符，不再另设单条 800 字符上限。超额保存保留原内容并提示使用 Wiki。放宽 Wiki 的非必要格式约束，保留来源和版本校验；一个整理目标失败不再阻断其它合法内容的保存。
- **子任务成果与远程文件**：子 Agent 的 Artifact 保留正确归属并支持打开；改进远程交付、项目文件导航和预览链接，PDF 读取在独立 worker 中完成。
- **更简洁的桌面**：设置页按需创建，统一图标、工具行、运行状态和操作按钮；修正主题颜色刷新、推理内容滚动与窗口返回等交互。
- **英文界面预览**：在“设置 → 通用 → 外观”选择 English，保存并重启后生效。常用设置、工具和运行检查已接入翻译，用户输入与已有资料不会被改写。

## 下载与升级

提供 **Windows x64 完整便携版**，包含原生桌面、CLI/TUI、Web、本地 OCR、交互 Shell 与随包资料，无需另装 Python。

1. 下载 `pycat-0.2.2-windows-x64.zip` 和同名 `.sha256` 校验文件。
2. 完整解压到新目录，在 `pycat-windows-x64` 中运行 `pycat.exe`；不要只替换单个 EXE，也不要覆盖正在使用的旧目录。
3. 命令行入口为 `pycat-cli.exe`，`--version` 应显示 `PyCat 0.2.2`。
4. 选择模型与项目开始使用。应用继续使用已有用户数据；升级前建议备份需要保留的会话和项目 `.pycat` 目录。

Memory 的新限制不会截断已有超额记忆，仍允许读出和删减。历史上已经产生的不完整摘要不会被升级自动重写，需要从保留的原始历史重新构建。

## 当前边界

- Windows 深层路径可能使附件快照或远程下载超过系统路径限制，请使用较短的项目和数据目录。本轮深层测试目录复现了该问题；较短临时目录中的完整回归通过，不代表长路径问题已修复。
- Windows PowerShell 停止后立即清理日志的偶发占用仍在跟踪；本轮常规回归通过，不宣称已确认历史竞态的根因。
- 英文界面仍为预览，部分提示可能保留中文。账号登录集成仍属实验功能，模型权限与额度由上游服务决定。
- 离线和本地固定服务检查不替代真实模型、外部 MCP、SSH 主机及消息平台验收。当前没有 Linux/macOS 二进制附件，Windows EXE 尚未代码签名。

## English overview

PyCat 0.2.2 improves independent conversation execution, interrupted model calls, context compaction, durable memory and child-agent artifact access. It also streamlines desktop controls and introduces an English UI preview, available under Settings → General → Appearance after a restart.

Project memory and user preferences each allow 8,000 characters. Over-capacity writes preserve existing notes and suggest saving detailed project knowledge in Wiki. Failed or incomplete model responses can no longer become successful context summaries.

Download and fully extract the Windows x64 portable ZIP. Keep the entire folder together and run `pycat.exe`; the CLI entrypoint is `pycat-cli.exe`. Existing user data is retained. Deep Windows paths and intermittent PowerShell log cleanup remain known limitations; previously incomplete summaries require rebuilding from their original history.
