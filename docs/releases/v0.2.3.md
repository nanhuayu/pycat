# PyCat v0.2.3

0.2.3 统一跨端语言与资源设置，增加终端猫形图标，并完善文件工具、研究方法、知识整理及上下文维护。

构建日期：2026-09-29。提供 Windows x64 完整便携包及 Python wheel / sdist，Windows 成品检查与包完整性校验通过。

## 主要更新

- **跨端中英文**：桌面、TUI、CLI 和 WebUI 共用语言设置与翻译源。保存后重新打开桌面或终端、刷新网页生效；远程客户端沿用宿主语言。用户内容、工具载荷和协议标识保留原值。
- **终端欢迎区**：从 PyCat 品牌图派生彩色猫形字符图，窄屏或较矮窗口自动收起，开始会话后保留消息空间。
- **技能与 MCP 设置**：合并重复列表与发现入口，收敛搜索、状态、安装和详情操作；统一新增、编辑弹窗及设置操作按钮。
- **文本读取与图像查看**：`file__read` 负责文本、PDF 文本等有界读取，`file__view` 提供图像与 PDF 页面视觉输入；改进空文件、行范围、大文件及文件搜索反馈。
- **搜索与复制**：明确区分搜索无结果和提供商失败，修复工具参数、执行结果等文本区域的键盘复制，并提供复制入口。
- **研究与知识整理**：新增按需加载的 `deep-research` 内置技能，完善子 Agent 用途、Todo 引导及 Memory/Wiki 整理边界；机制回归不代表真实模型研究质量已完成验收。
- **上下文维护**：复用历史用户轮摘要并处理长用户轮，改进压缩的推理强度、参数回退及历史前缀选择；工具内容压缩继续沿用独立边界。

## 便携包与使用

完整包包含原生桌面、CLI/TUI、Web、本地 OCR、交互 Shell、内置技能和随包用户资料，无需另装 Python。

解压后保持 `pycat-windows-x64` 整个目录，桌面入口为 `pycat.exe`，终端入口为 `pycat-cli.exe`。`pycat-cli.exe --version` 应显示 `PyCat 0.2.3`。升级时使用新目录，避免覆盖正在运行的旧版本。

语言可在桌面或网页“设置 → 通用”修改，也可使用 `pycat-cli.exe config set app_settings.language en`；改回中文使用 `zh_CN`。

## 当前边界

- Windows 深层项目和数据路径可能使附件或远程缓存超过系统路径限制；短路径复测通过不代表长路径已修复。
- Windows Shell 停止后立即清理日志的文件占用问题仍在跟踪，成品功能检查不能替代该生命周期问题的源码回归。
- 中英文覆盖应用自有界面文案，技能正文、第三方描述、服务诊断和部分系统提示保留来源语言。
- 离线与本地固定服务检查不替代真实模型、外部 MCP、SSH 和消息平台的部署验收。Windows EXE 尚未代码签名。

## English overview

PyCat 0.2.3 shares UI language settings and translations across desktop, TUI, CLI and WebUI, adds a responsive terminal cat mark, and simplifies Skills and MCP management. It also separates bounded text reading from image viewing, adds a built-in deep-research workflow, and improves knowledge curation and context maintenance.

The Windows x64 portable package includes the desktop, terminal and web interfaces, local OCR and bundled resources. Keep the extracted directory together. Existing Windows long-path and Shell log-cleanup limitations remain under investigation. Download the Windows portable ZIP, Python wheel or source distribution from the assets below.
