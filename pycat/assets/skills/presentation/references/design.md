# Composition and review

Start from the audience, purpose, evidence and intended conclusion. Decide which points deserve their own page and which work better as a table, chart or supporting note. Follow the user's requested structure rather than a fixed number of slides.

Use a restrained palette, readable type hierarchy, aligned margins and consistent treatment of related pages. Repeated layouts are useful for comparisons; vary them when the content changes. Avoid decorative elements that reduce reading space. A clear text-led page is acceptable when a chart or image would not explain more.

Charts must use actual values, labels and units. Cite the source and date where needed. State estimates and missing data. Keep source images faithful; illustration generation is a separate user-directed action through available image tools.

Review title/body hierarchy, content coverage, notes, image references, tables and numeric values. Inspect native output structure, then review final appearance with an available PowerPoint viewer or an explicitly verified conversion to PDF. The bundled builder does not provide a faithful HTML/raster preview. Report visual coverage honestly.
